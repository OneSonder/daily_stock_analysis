# Chapter 13: Bulletproof Systems

## Core Idea
Trading is a boxing match, not a sprint. Build for an **unknowable future** with diversity and simplicity — not a single historically maximal system.

## Frameworks Introduced
- **No perfect system**: Omega may beat Alpha only because past market-state mix favored it.
- **Robust trading program**: Perform acceptably across futures you cannot predict.
- **Nature analogy**: Ecosystems survive via diversity; hardy organisms survive via simplicity/adaptability.
- **Adapt via filters**: Portfolio filters keep systems out of unfavorable states.
- **Market + system diversification**: Many uncorrelated markets and multiple system types.

## Key Concepts
- **Quiet vs volatile trend regimes**: Relative system rankings flip with regime mix.
- **Insufficient sequence length**: Q/V strings too short to forecast next regime confidently.
- **Liquidity constraint**: Primary valid reason to exclude markets; illiquidity hurts most when you must exit into empty books.
- **Coffee 1985/86 missed trade**: Dennis barred coffee for volume; Faith estimates ~$14M / ~280% on his $5M sleeve for the missed trend — liquidity rationing has huge opportunity cost but can be rational.
- **Trader memory / system diversification**: Multiple styles so something works when one style suffers.

## Mental Models
- Optimize for survivability across unknown distributions, not max backtest score.
- Add markets that add opportunity without adding near-identical correlation.
- Prefer simple durable concepts over niche-condition complexity.

## Anti-patterns
- Picking one "best" equity curve and going all-in.
- Excluding markets solely because a short test looked unprofitable (cocoa-style delayed trends).
- Single-market thinking forced by single-market test platforms.
- Trading illiquids because "my account is small so impact is fine" (crowd of orders still exists).

## Worked Example
Omega beats Alpha in 20y test with 13 quiet-trend years vs 7 volatile. If volatility rises going forward, Alpha may win. You cannot know from short Q/V sequences. Solution: robust portfolio — diverse markets + simple adaptive systems + multiple styles — rather than betting the farm on Omega.

## Key Takeaways
1. Future market-state mix is unknowable.
2. Diversity + simplicity = robustness.
3. Filters adapt systems to states.
4. Liquidity is the main hard exclusion rule.
5. Missed coffee trade: constraints have costs; still trade the process.
